# Deadlock Detector (Modelo Matricial)

Um utilitário desenvolvido para a disciplina de Sistemas Operacionais que implementa a detecção de *deadlocks* em sistemas computacionais utilizando o **Modelo Matricial**.

O programa analisa matrizes de alocação e requisição de recursos para determinar se o sistema entrou em um estado de impasse (deadlock) entre processos e semáforos.

## 🛠️ Tecnologias
* **Linguagem:** Java
* **Conceitos:** Sistemas Operacionais, Gerenciamento de Processos, Semáforos, Prevenção de Impasses.

## ⚙️ Exemplo de Uso
**Entrada (Matriz de Requisição e Alocação):**
*Por meio da interface gráfica, estancie os recursos, processos e identifique o tempo que cada processo precisa para utilizar um recurso. Inicie a simulação, o programa irá alertar se houver algum deadlock entre processos.*

**Saída Esperada:**
`Deadlock Detectado nos processos P1 e P3.`
